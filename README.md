# Companions to the System of Inevitability

A small static library for five free, evidence-based companion books to the System of Inevitability, by **Cory Snell**, creator of the System. The books explore movement, juggling, close-quarters striking, flow, embodied attention, and the mind.

Anyone may read the books in the browser or download them as PDF or EPUB.

**License:** [Creative Commons Attribution–NonCommercial–ShareAlike 4.0 International (CC BY-NC-SA 4.0)](https://creativecommons.org/licenses/by-nc-sa/4.0/). Free to share.

## The books

1. *Walking and Turning* — Iron, Spirals, and the Science of a Practicing Mind
2. *Wave and Return* — The Bent Fist, the Figure-Eight, and the Science of a Restrained Hand
3. *Shape and Choice* — Everyday Geometry, Calm Presence, and the Science of a Choosing Mind
4. *Lens and Lattice* — Altered Perception, the Internal Arts, and the Science of a Curious Practice
5. *Nucleus and Orbit* — Atoms, Necessity, and the Science of an Interwoven Practice

## Reading the site locally

The site is self-contained. There are no external scripts, fonts, or trackers. From this directory:

```bash
python3 -m http.server 8000
```

Then open <http://127.0.0.1:8000/>.

All links are relative, so the site also works from a GitHub Pages project subpath such as `https://USERNAME.github.io/REPO/`. A `.nojekyll` file is included so GitHub Pages will not process the files with Jekyll.

## Internet Archive

Suggested item identifiers and metadata for an Archive.org upload are in [`ia/`](ia/):

- `walking-and-turning-inevitability-companions-1`
- `wave-and-return-inevitability-companions-2`
- `shape-and-choice-inevitability-companions-3`
- `lens-and-lattice-inevitability-companions-4`
- `nucleus-and-orbit-inevitability-companions-5`

Each JSON file lists the identifier, title, creator, description, subjects, license URL, and the local PDF, EPUB, and cover files to upload.
